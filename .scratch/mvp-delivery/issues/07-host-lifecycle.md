Status: needs-triage
Type: task
Batch: B
Blocked by: 05, 06

## 目标

让业务 Host 独立于桌面窗口运行，并建立受认证的本地连接。

## 依赖

[05](./05-second-agent-matrix.md)、[06](./06-app-plugin-sdk.md)。本任务为待评审计划，尚未开始实现。

## 验收

- 单实例锁、启动/附着/停止、状态与健康查询可用；重复启动不创建第二个 Host。
- 本地仅监听 loopback，使用受限权限交付连接密钥，校验认证和 Origin。
- 客户端断开不终止 Agent；明确停止 Host 时处理进程树、资源与退出结果。

## 建议提交切片

1. Host 进程入口、实例锁与附着。
2. 本地认证和健康查询。
3. 独立存活与退出策略。

每个切片完成相关验证后单独提交；新增失败或代码变动才扩大验证。未通过本任务验收时不标记完成。
