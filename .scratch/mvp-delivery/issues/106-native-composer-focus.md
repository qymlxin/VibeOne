# 106 · 原生指令菜单焦点恢复竞争

Status: resolved
Type: task
Blocked by: none

## 直接证据

升级后的真实Tauri WebView中，在空输入框之外点击「选择指令」，实际插入/、发送按钮启用，但指令菜单未显示；AX与截图均确认。原生最小复现清空输入框→焦点移到搜索栏→点击指令，2.4秒稳定失败。当前Chromium回归未覆盖该焦点顺序。

## 验收

- 先固定能捕获该症状的回归，查明焦点/选区状态竞争或其他根因，保留真实用户焦点重新打开与Esc语义。
- 指令和@引用快捷入口从未聚焦输入框也能打开，选择与光标正文不受影响。
- 桌面/手机回归，实际更新后的Tauri WebView原操作复验；文档更新并单独提交。

## Answer

根因为受控文本写入后的程序化focus早于选区恢复，onFocus按旧光标0重新计算并清掉触发词。仅在该选区恢复期间抑制focus重算，普通重新聚焦和Esc语义保留。确定性焦点顺序回归先17.4秒失败，再桌面76.2秒与HTTPS手机25.4秒通过。835.00MiB更新包及仓库外冒烟通过。

真实Tauri WebView原操作复验：清空→搜索栏聚焦→点击指令，菜单实际显示；同顺序点击引用文件后筛选preview.txt，Tab选择产生引用卡片。移除测试引用、归档独立临时验收会话并恢复原会话视图，未发送模型任务。安全升级前检查六会话无执行/排队及原五会话无草稿，在线备份SQLite。原生目录选择及退出桌面Host仍存活已有实际证据；系统通知/托盘和运行中退出仍独立待验。
