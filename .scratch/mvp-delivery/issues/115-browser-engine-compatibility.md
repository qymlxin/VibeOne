# 115 · 浏览器搜索兼容性后续

Status: unclaimed
Type: task
Blocked by: none

## 现状

114后HTTPS导航与浏览器产品标记已修正，但实际百度搜索仍触发站点安全验证。需要用户完成站点的正常验证才能确认该浏览会话后续行为；不自动解题、不复制其他应用Cookie或账号。

## 待处理

若继续追求与Chromium浏览器相同的兼容范围，评估独立Chromium组件与Tauri窗口集成、进程/存储/标签生命周期、IPC隔离和更新分发成本。不能用Chrome UA冒充已完成内核替换，也不能保证替换内核就消除站点验证。当前仍保留Tauri/WebKit，不在此票下直接迁移整个桌面技术栈。
