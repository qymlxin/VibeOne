## 验收

- 工作区、Profile、会话、Run、队列和待处理有类型化 DTO 与错误码。
- 命令幂等键重复得到同一结果，键相同但内容不同拒绝；长操作返回 202 和 operationId。
- 查询返回当前状态，操作可按 ID 对账；设备权限校验位于 Host。
