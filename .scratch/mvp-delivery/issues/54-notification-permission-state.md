# 54 · 通知权限状态与首次连接基线

Status: resolved
Type: task

## 范围

原型通知页包含系统权限状态，正式页目前只保存本设备开关。增加实际权限查询与刷新、拒绝/不可用/查询失败反馈，并保持关闭仅停止本设备通知。首次连接收到历史快照时建立基线，不能补发所有历史执行提醒；随后新审批、输入和执行结束仍应提醒。

## 验收

- 原生桥接与浏览器分别使用真实API；不把本地开关等同系统已授权。
- 自动回归覆盖权限未授权、开启、刷新后外部撤销、关闭，以及冷启动不补发旧提醒、新事件仍提醒。
- 中文文档同步；操作系统弹窗是否出现另记原生实机验收。

## Answer

已拆开本设备提醒偏好与系统权限状态，增加异步查询、刷新、窗口聚焦同步和失败反馈。发现Tauri通知插件桌面权限API固定返回Granted，macOS因此接入真正的UserNotifications查询/请求命令，采用有超时的系统回调。浏览器使用Notification API，不支持或非macOS缺少查询时如实说明。首次有效快照建立通知基线，后续新事件正常提醒。

验证：桌面真实Host/原生桥接夹具回归53秒通过，覆盖查询失败、拒绝/授权/撤销/关闭、具有通知权限时冷启动零补发及新Run发送；HTTPS手机只读权限查询和窄屏通过。原生4项测试、编译与Clippy通过；中文说明、macOS最低10.15要求及SVG已记录。Mac锁屏下不能验证实际授权框/系统横幅，由52继续，不把夹具当实机。
