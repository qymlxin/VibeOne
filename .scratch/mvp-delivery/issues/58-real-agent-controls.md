# 58 · 真实 Agent 审批及取消验收

Status: resolved
Type: task

## 范围

新增显式运行的真实Codex交互烟测，使用独立Host及临时工作区，在当前会话只读模式验证批准、拒绝、旧请求失效与运行中取消。不能用演示Agent替代。保留真实上游审批选项，不修改用户全局权限。

## 验收

- 批准一次后仅目标临时文件产生预期内容。
- 拒绝后目标文件不存在；重复/旧请求不能改变决定。
- 执行中取消返回终止状态，无后续写入。
- 失败和认证缺失如实记录，退出清理独立进程及临时目录。

## Answer

新增显式交互烟测 `npm run agent:controls`，实际Codex通过批准一次写入、拒绝不写入、已决定请求不能改选、停止待审批后不能再批准，以及真实长耗时工具进程退出。不是只检查Run状态；从进程表确认唯一标识子进程存在并退出。取消后继续的真实任务成功，权限模式恢复为read-only。

另以 `-- --input-only` 验证计划模式的真实elicitation/create结构化选择；非法选项被Host拒绝，合法选项到达Codex并出现在回复，旧请求不能改为拒绝。报告仅保存检查结果，不保存令牌；脚本使用隔离Host/工作区，退出清理。Claude认证、原生窗口及物理手机仍不在这些通过证据内。
