Status: resolved
Type: task

## 范围

工作区导入、Profile 保存/移除由明确的领域错误类型决定 HTTP 状态及稳定错误码，不依赖中文说明匹配。覆盖不存在、无效输入、修订冲突、容量限制、存储不可用及内部错误；保留现有错误信封和幂等/固定配置语义。真实 Host 集成验证，更新文档。其他业务路径的旧错误映射继续由14跟进。

## 实现

新增内部 DomainError/ErrorKind；目录写入直接返回类型，Profile 调用保留错误身份。两个 HTTP 入口维持独立命令任务，将类型映射到原有统一错误信封。存储失败只公开固定说明，禁止成功状态发布；原有 String 路径仍有显式兼容边界。新增 HTTP 集成与真实存储关闭验证，文档及 SVG 已更新并渲染核对。
