# 91 · 文件目录导航与读取失败恢复

Status: resolved
Type: task
Blocked by: none

## 目标

编辑目录输入不改变当前列表，确认且Host读取成功后才切换。失败保留当前目录、选择和可编辑地址；提供目录层级返回与子目录重试，避免永久加载提示。

## 验收

- 编辑/提交有效与不存在路径、Host失败都保持明确状态。
- 当前目录导航可以返回父目录和工作区；含空格路径正常。
- 子目录读取失败后显示错误及重试，不能一直显示正在读取。
- 共享同一目录正在执行的读取，过期会话响应不覆盖新界面。
- 正式浏览器验证并更新功能文档，独立提交。

## Answer

地址草稿与当前目录分离，异步成功后再切换；失败保留原列表、选择与地址。新增当前目录层级返回、子目录错误和重试，同路径请求共享Promise，过期会话结果被隔离。错误映射保留无原型对象，读取在登记后启动，避免特殊目录名和同步拒绝破坏请求合并。

验证：55项Node/SDK；正式桌面68.8秒覆盖HTTP503重试、有效/无效地址、含空格路径、列表保持和根目录返回；HTTPS手机23.6秒、无溢出断言通过；亮暗及手机截图和SVG已查看。833.71MiB桌面包及包外资源烟测通过，Host仍为fb423a3d48a871e0d8cbe8f7f91e1bc114ebe56b55e0519955ceed35c6eb9f17（本项未修改Rust）。

文档已更新。未重启用户实际Host；14的其余动态接口及52原生/真实Claude/物理设备验收继续保留。
