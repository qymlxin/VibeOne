# 92 · 设备公开状态与授权一致性

Status: resolved
Type: task
Blocked by: 89, 90

## 目标

设备列表区分有效、过期、撤销和异常记录，显示实际授权工作区。公开响应使用明确字段和生成类型，不能把设备存储的未知私有字段透传给客户端。异常授权字段不能作为有效设备凭据使用。

## 验收

- 过期与异常记录不会显示为已授权；保留明确撤销入口。
- 状态响应仅返回允许的公开字段，包含角色、范围及到期时间。
- HTTP身份、配对凭据交付和页面状态使用一致的有效性规则。
- 真实存储/Host及桌面/手机验证通过，文档与SVG同步，独立提交。

## Answer

设备公开响应改为RemoteDeviceSummary与角色/状态枚举，不透传存储JSON；页面显示授权范围、完整到期时间及active/expired/revoked/invalid。异常标识、角色、范围、撤销字段、到期时间与摘要不能用于授权；身份、重复决定和配对凭据交付共用判断。缺少标识的记录仍显示说明，撤销入口明确禁用。
