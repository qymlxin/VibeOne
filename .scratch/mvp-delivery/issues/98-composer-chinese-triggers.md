# 98 · 指令和引用输入验收与中文触发

Status: resolved
Type: task
Blocked by: none

## Goal

响应用户的 `/` 指令和 `@` 引用请求，核对正式输入框的菜单、键盘选择、引用卡片及实际发送链路；补全中文正文和标点之后直接输入触发符的交互。

## Acceptance

- `/` 展示上游 ACP 指令、工作台操作和项目技能；`@` 展示真实文件、目录及项目技能。
- 中文或中文标点后直接输入触发符可以打开菜单，邮箱和 URL 不被误识别。
- 选择后保留周围正文；引用可以移除，选择本身不发送任务。
- 浏览器真实 Host 回归通过，核对亮暗模式；更新功能文档并单独提交。

## Answer

正式输入框已有 ACP 指令、工作台操作、项目技能、文件及目录引用的真实发送链路。本次补全中文正文与标点后的直接触发，保留邮箱和 URL 的边界；补充中文触发后的键盘选中、保留正文和移除引用回归。功能范围继续为项目内技能与当前工作区文件，不扩展为截图中其他产品的全局插件市场。

验证：15 项输入框及相关单元测试通过；真实 Host 桌面集成测试通过（约 70 秒），包含中文触发、技能内容发送、目录清单发送、键盘选择、亮暗模式和会话交互。亮暗截图已查看。功能说明更新于 `docs/composer-interactions.md`，调用链沿用 `docs/diagrams/composer-flow.svg`。
