## 启动与升级

源码运行：`npm ci && npm run desktop`。打包：`npm run desktop:bundle`；生成 `apps/desktop/src-tauri/target/debug/bundle/macos/VibeOne.app`。

退出旧桌面进程，再打开新版应用。关闭窗口会隐藏到托盘；托盘提供“打开”“退出桌面（主机继续运行）”“停止所有执行并退出”。如果提示主机版本较旧，先结束执行，在设置中重启主机。旧内存版会先导出历史，已有 SQLite 版直接执行数据库迁移。

本版 Host 能力标识为 `apiVersion: 3`。桌面 IPC 负责主机生命周期、目录选择、证书导出和系统通知，业务通过 HTTP/WS 进入 Host。

运行需要本机Node.js 22+。本地包携带Host、手机页面、插件运行时、SDK、示例插件和两个固定ACP桥接器的生产依赖闭包；认证仍由本机提供，也可通过Agent Profile指定其他启动程序与参数。正式签名、公证、跨机器依赖分发不在本轮自动验收结论内。

## 统一数据目录与项目

桌面默认使用 `~/.vibeone`（主目录不可写时自动使用现有可写的 `~/.config/vibeone` 或 `~/.local/share/vibeone`，设置显示实际路径）：SQLite 保存统一会话/配置/插件索引，`projects/project-<id>/` 保存未选择目录时自动创建的项目文件。选择已有工作区时仅关联原目录，不复制或移动工程。新建会话不要求先选目录；可在工作区列表中复用先前项目。远程设备仍只能选择已授权工作区。

旧桌面数据目录在 Host 空闲时自动停止并原子迁移，旧路径保留为兼容别名，避免已有插件固定路径失效。活动执行期间继续附着旧 Host，设置中提示待迁移；目标目录已有数据时不覆盖或合并。

- [ ] 不选择目录，创建会话并发送；确认工作区位于 `~/.vibeone/projects/`。
- [ ] 再建一个默认项目，确认目录独立；选择上一个目录可共享项目文件。
- [ ] 旧历史会话点击“在新上下文继续”，确认历史保留、新消息可发送；旧消息不会自动发送给 Agent。

## 手机连接步骤

1. 桌面设置中选择本机局域网或已有可信网络 IP，开启 HTTPS 手机入口。不会监听通配地址、映射路由器端口或建立公网 Relay。
2. 导出 `VibeOne-Root-CA.crt`，通过用户自己的可信方式传到手机，按手机系统流程安装并信任此 CA。证书只包含公钥，私钥保留在 Host 数据目录。更换监听 IP 会重新签发证书，需重新检查信任。
3. 手机打开设置页显示的 HTTPS 地址或扫描二维码；在电脑生成 5 分钟配对码，手机填写设备名称和配对码。
4. 在电脑核对请求并选择工作区和权限。viewer 只查看；approver 可查看及审批；operator 可查看、发送、取消、处理补充输入和审批。手机不能管理插件、设备授权或停止整个 Host。
5. 手机凭据使用 Secure、HttpOnly、SameSite=Strict Cookie，不放进 URL；服务端只保存凭据哈希。撤销后 HTTP 请求拒绝，已有 WSS 连接关闭。

- [ ] iOS 真机 CA 信任、HTTPS/WSS 连通。
- [ ] Android 真机 CA 信任、HTTPS/WSS 连通。
- [ ] 手机 viewer 越权操作被拒绝，换 operator 后可发送与审批。
- [ ] 电脑和手机同时处理同一审批，只接受一个决定。
- [ ] 手机断网时只保留草稿，禁止提交审批；网络恢复后以 Host 快照恢复状态。
- [ ] 撤销设备后，已打开的手机页面退出授权状态。
- [ ] 切后台、锁屏、Wi-Fi 切换、Host 重启后的实际表现。

浏览器自动化对手机页面使用测试环境的证书忽略选项；另一条 HTTPS 测试使用生成的 CA 做真实证书校验。二者不能证明手机操作系统已经信任证书。真机项目保持待验状态。

- 重启后的历史默认暂停执行，可点击“在新上下文继续”在同一会话发送；暂停队列可以明确选择“在新 Agent 上下文执行”，保留旧历史，但不恢复旧工具进程或隐藏思考状态。不同连接的上游消息 ID 已隔离，避免复用 ID 覆盖历史。
- 当前会话运行投影保留128条消息与100项工具，完整消息/工具档案可分页读取；单条消息最多65,536字符并明确提示截断。首次升级依据原始事件回填，旧导出缺少早期事件时会说明可恢复范围。详见 [持久历史](conversation-history.md)。
- 队列容量 20、会话 Run 上限 1000、未归档会话上限 128；文本引用每次最多 5 个且每个 32 KiB；文本预览/产物最多 256 KiB，截断会明确显示。上传附件已支持图片、纯文本及嵌入文件：单文件4MiB、每条最多5个且总量16MiB，每会话500项/256MiB；按Agent实际媒体能力发送。详见附件文档。
- 事件日志提供稳定 ID、游标和分页查询；桌面与手机当前依靠 WS 通知后获取快照恢复，尚未使用增量 reducer 或提供事件日志保留策略。
- 审批投递状态表示本地 ACP 响应路径的状态，不能证明 Agent 已执行工具。投递不确定时不自动重放批准。通知使用事务 outbox、稳定 eventId、最多三次退避重试，旧待处理通知在重启后丢弃；插件对外部副作用需按 eventId 幂等。
- 插件是可信本机代码，Node 原生 API 不属于 Host 文件 API 的安全边界。当前插件采用单文件 App ESM、自包含依赖、严格 API 范围；跨插件依赖解析、市场、签名与自动进程重启未开放。自动重启预算为 0，失败由管理页人工重新启用。
- 通知在桌面进程运行时可用，窗口可以隐藏；彻底退出桌面后 Host 继续工作，但内置桌面通知监听不保活。手机网页没有锁屏 Web Push 保证。
- Claude真实认证与交互、真机网络与证书、桌面托盘/系统通知、跨平台和正式签名公证仍需上述人工验收；Codex真实审批、输入和进程取消已有独立烟测证据。
