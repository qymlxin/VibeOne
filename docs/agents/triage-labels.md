# Triage labels

Use the following default labels for local issues, recorded near the top as `Status: <label>`.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent to implement |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

When a skill refers to a triage role, use the corresponding label from this table.
