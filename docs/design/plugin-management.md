# 插件管理界面

插件页沿用工作台原型的中性亮暗底色、系统字体和线性图标。默认打开已安装插件，日常管理与获取新插件分开。

## 布局

顶部为「已安装 / 获取插件」切换，本地安装放在右侧次级入口。已安装采用左列表、右详情：列表支持名称搜索和启停状态筛选，使用对应功能图标、版本及运行指示；详情顶部集中显示名称、版本、状态和启停开关，下方为检查仓库更新、配置与授权两个动作。

功能、中文权限、授权工作目录、安装来源分别成组。目录使用可截断标签，完整路径通过悬停查看。代次、内部ID及安装路径收在技术信息中；操作回执、进度和结果放在底部折叠区。没有设置贡献的插件不显示空面板或孤立ID标题。

获取插件页使用单一仓库输入区、解析前说明和解析后清单。列表沿用功能图标，选中行提供底色反馈；授权区在选择插件后出现，批量结果保留成功/失败反馈。配置页面提供清晰的返回入口、目录检查、授权范围和JSON配置。安装后返回已安装并定位插件。

## 状态与适配

按钮具有悬停、焦点、禁用状态；空列表支持进入获取插件，搜索为空提示调整条件。亮暗模式复用主题变量。窄窗口下列表与详情改为上下布局，长名称和来源不撑开容器。隐藏表单不会继续挤占布局。

页面改动随功能设计一起交付，不把仅可操作的默认表单作为完成态。验证聚焦本页：列表选择、搜索、视图切换、仓库多选安装和配置返回，检查亮暗渲染；不运行全量回归。
