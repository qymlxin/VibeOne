# 桌面视觉对齐

正式桌面以已批准的三栏工作台和设置原型为视觉基准（Git提交57bccce），不再以“功能可用”替代视觉验收。原型中的演示消息、分支、统计和认证状态不进入真实数据；相同状态与内容下，对齐布局、尺寸、色阶、字号、间距及动画。

| 区域 | 基准 |
| --- | --- |
| 顶栏 | 全窗40px；会话名/连接状态与右侧工具入口 |
| 左栏 | 224px；品牌与新建、搜索、待处理、会话分组、底部主机/设置 |
| 聊天标题 | 72px；标题与单行工作区/Agent/状态，管理动作不另占一行 |
| 正文 | 最大770px；42px内边距，14px正文，轮次间隔36px |
| 输入区 | 最大730px；18px圆角，52px正文、单行工具区 |
| 右侧 | 默认38%；47px工具标签，文件/差异保留独立树与代码滚动 |
| 设置 | 224px导航；780px主要内容，分组标题与中性色表单容器 |

亮色背景#FFFFFF、前景#1A1C1F，暗色背景#181818、前景#FFFFFF；沿用批准后明确指定的色值。自定义外观继续按设备保存，不被布局重构覆盖。手机采用原有单列和44px操作目标。

验证使用相同视口查看实际渲染与批准截图，核对主体边界及计算尺寸；动态业务内容只比较其对应组件。功能回归覆盖真实Host消息、指令引用、工具切换、配置、重试、持久历史及HTTPS手机。每个切片记录通过范围，整票完成前不宣称全部一致。

## 有数据的设置状态

插件详情采用与原型一致的对象标题、运行状态、权限与贡献分组。版本、代次、工作区名称、扩展点和能力均从实际插件清单与Host状态读取；声明能力与当前授权分开显示。App界面仅放入所属插件的详情，切换对象不会混入其他插件的设置。

停用开关调用持久生命周期操作，已受理的旧代次继续按现有租约规则排空。重新启用时先打开检查表单，保留已确认的工作区和配置，但清除信任勾选；用户重新确认后才安装/发布，Host确认前开关保持关闭。安装成功返回对应详情，并将键盘焦点放回安装入口。

Agent配置采用对象标题、入口状态、连接信息和启动配置分组；环境探测仍使用真实调用，不把入口存在等同于认证成功。通知与HTTPS入口复用同一开关组件，只有实际状态变化后才更新显示；手机保留44px操作范围。

## 直接迁入原型

用户明确要求停止叠加式靠近原型后，正式桌面改为直接使用批准原型的组件结构与样式。`approved/review.css` 与 `approved/settings-review.css` 和57bccce原始文件逐字一致，SHA-256分别为 `e06013e8a7e02816a9380e114ac33fc8d664405052547f0e859eda1df3e3362e`、`95825a0f6ec6a88debd035eb2de432e41350ff383707334f01800433300afe1f`。外观页直接复用原型Appearance组件，仅将演示说明改成实际持久行为。

顶栏、聊天标题、固定阅读容器、用户气泡、输入框两组工具区、右侧标签和设置行采用原型结构。旧 `workbench.css`、`workspace-layout.css`、`desktop-parity.css` 已退出桌面并删除。旧手机规则隔离到800px以下；实际审批、历史恢复、错误重试等业务状态独立保留，视觉基线由原型样式负责。

四个主要工具入口移到顶栏，执行记录、产物和Agent设置在“更多工具”中；会话重命名/归档收进标题菜单；附件、指令和引用收进输入框加号菜单。原有Host命令、幂等键、权限和失败重试链路不变。

会话栏默认使用“项目＋最近”：当前工作区会话放在项目下，其他会话列于最近；完整的项目分组、纯最近排序和归档筛选收进列表选项。长会话标题保持单行省略，完整名称仍通过会话内容和提示可读。手机端独立保留44px操作目标、单列文件树和固定顶栏，避免桌面原型的窄宽度隐藏规则覆盖手机功能。
