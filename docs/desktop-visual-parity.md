# 桌面视觉对齐

正式桌面以已批准的三栏工作台和设置原型为视觉基准（Git提交57bccce），不再以“功能可用”替代视觉验收。原型中的演示消息、分支、统计和认证状态不进入真实数据；相同状态与内容下，对齐布局、尺寸、色阶、字号、间距及动画。

| 区域 | 基准 |
| --- | --- |
| 顶栏 | 全窗40px；会话名/连接状态与右侧工具入口 |
| 左栏 | 224px；品牌与新建、搜索、待处理、会话分组、底部主机/设置 |
| 聊天标题 | 72px；标题与单行工作区/Agent/状态，管理动作不另占一行 |
| 正文 | 最大770px；42px内边距，14px正文，轮次间隔36px |
| 输入区 | 最大730px；18px圆角，52px正文、单行工具区 |
| 右侧 | 默认38%；47px工具标签，文件/差异保留独立树与代码滚动 |
| 设置 | 224px导航；780px主要内容，分组标题与中性色表单容器 |

亮色背景#FFFFFF、前景#1A1C1F，暗色背景#181818、前景#FFFFFF；沿用批准后明确指定的色值。自定义外观继续按设备保存，不被布局重构覆盖。手机采用原有单列和44px操作目标。

验证使用相同视口查看实际渲染与批准截图，核对主体边界及计算尺寸；动态业务内容只比较其对应组件。功能回归覆盖真实Host消息、指令引用、工具切换、配置、重试、持久历史及HTTPS手机。每个切片记录通过范围，整票完成前不宣称全部一致。

## 当前验证

第一切片已落地窗体/会话栏/聊天/输入区/右侧工具导航和文件浏览，以及设置导航、常规分组和共有表单层级。`npm run desktop:visual` 使用隔离真实Host、1600×1000视口，断言40/224/72/730/52px几何及47px面板标签、无横向溢出，并保存亮暗聊天、四面板及八类设置截图至系统临时目录 `vibeone-parity-107`。该检查是结构与截图证据，不是跨平台逐像素相等证明。

桌面完整回归75.2秒、视觉10.8秒、HTTPS手机25.3秒通过。对照图仍发现插件/远程内容布局需进一步还原；原生Overlay待实机核对，107保持进行中。

第二切片进一步对齐远程入口/配对分组与插件安装入口；自定义颜色覆盖顶栏、侧栏、输入表面与右侧预览。桌面72.3秒、亮暗视觉10.7秒、HTTPS手机24.1秒、61项Node/SDK及5项原生单元通过。最终安装图标改用共用SVG图标后，视觉10.4秒复验通过。

835.04MiB调试包及仓库外资源冒烟通过。实际Tauri已加载本版，核对40px Overlay顶栏、三栏文件面板、常规设置和亮暗切换，恢复原会话及暗色；六个会话的全部消息、Run、标题、工作区及归档状态与升级前逐项相同。原型一致性仍需覆盖已安装插件、已有配置、复杂表单、长标题和人工等待等更多状态，不能将当前截图描述为全部逐像素一致。
