# 原型功能补齐清单

范围来自已批准的三栏工作台 `prototype/three-pane-review`（57bccce）的 `review.jsx`、`SettingsReview.jsx`、`Appearance.jsx`、`SessionAvatars.jsx` 与 `ReadingRail.jsx`。以实际操作和端到端证据验收，不能用界面出现或演示状态代替实现。

| 原型功能 | 当前证据 / 缺口 | 后续验收 |
| --- | --- | --- |
| 会话创建、选择、搜索、归档、重命名、待处理 | 生产 Host 与桌面/手机测试已接通 | 总回归核对 |
| 项目分组、最近会话、侧栏开合及搜索快捷键 | 当前仍为平铺列表 | 接真实工作区分组及快捷键 |
| 消息分段、过程折叠、嵌套工具、思考扫光 | 生产时间线及流式测试已实现 | 总回归核对 |
| 回答复制、消息操作反馈 | 已接复制原始Markdown及反馈（46，回归通过） | 复制原始 Markdown，失败反馈 |
| 本轮变更摘要入口 | 已接实际文件数量的当前工作区变更卡片（46，回归通过） | 展示真实变更，明确工作区范围，不伪称全属 Agent |
| 右侧面板切换、关闭、调整宽度、扩大预览 | 已补扩大与恢复（46，回归通过） | 状态与窄屏验证 |
| 文件树、展开/收起、筛选、选中文件、面包屑 | 已实现真实按需目录树、筛选及选中态（45） | 真实多层目录、空格、刷新、错误与越界 |
| 文件行号、统一差异、增删着色、暂存切换 | 已实现行号、差异着色、增删数量和暂存切换（45） | 真实 Git 修改、行号及增删数量 |
| 终端执行输出、定位到对应对话 | 已按真实runId接定位（46，回归通过） | 使用真实 runId 定位，缺失时不捏造关联 |

| 输入框发送、队列、停止、/、@ | 已有真实链路 | 25 项 Node、桌面及 HTTPS 手机回归已覆盖 |
| 手动暂停下一轮队列 | 已增加手动暂停与恢复，正常结束保持暂停（48） | 增加显式暂停，当前Run继续、下一条不提升 |
| 附件入口 | 尚无图片/二进制附件 | 按 ACP 支持能力、安全限制实现实际传递与预览 |
| 输入框模型及权限选择 | 已共享ACP select/boolean原生控件（47） | 将上游可用值转为输入区选择控件，不虚构能力 |
| 阅读导航、悬停预览、点击/键盘跳转 | 已实现，当前投影仅128消息 | 补齐长历史浏览，确保导航覆盖可载入历史 |
| 会话头像颜色/形状与动效 | 已实现本设备持久化 | 总回归与减少动画核对 |
| 八分类设置、搜索、返回 | 已接真实设置 | 核对每个原型操作的落点 |
| 常规管理跳转、数据详情、队列规则展示 | 已补齐管理/数据跳转与规则说明（47） | 实际链接与信息补齐 |
| 外观、通知、Profile修订/恢复/移除 | 已接本地偏好、系统通知与Host API，恢复入口已补（47） | 实测保存、失败和修订隔离 |
| 工作区导入、插件检查/信任/配置/更新/启停 | 已接Host、App/Worker与代次租约 | 总回归 |
| HTTPS入口、证书、配对、角色/范围、撤销 | 已接Host与HTTPS浏览器测试 | 物理手机证书/软键盘另记人工待验 |

终端在批准原型中明示只读，因此保留只读设计。Skills/MCP 市场、订阅管理等没有进入批准的八类设置原型，不以其他产品参考截图扩大成本次功能承诺。真实 Agent 的认证和实际手机系统权限需要用户环境；不能因此跳过可由本机验证的实现。
