# 桌面侧栏拖动交互

左右侧栏沿用工作台原型，分隔条支持连续拖动、收起和恢复。左侧会话栏最小宽度为 200px，右侧工作面板为 280px；最大宽度受窗口剩余空间约束，为中间对话留出空间，左栏最多 480px。

![侧栏拖动流程](diagrams/sidebar-resize.svg)

## 操作与状态

- 拖到最小宽度以内，面板继续缩窄，透明度随宽度逐渐降低；在最小宽度的一半处完全收起。左栏阈值为 100px，右栏为 140px。
- 收起不结束拖动。保持鼠标按住并反向拖动，超过同一个阈值后重新出现，继续变宽、渐入。
- 松手时，收起的面板保持隐藏，其余面板回到至少最小宽度。左右栏分别记住展开宽度；右栏恢复此前的工作标签页。
- 已收起时，窗口边缘仍可拖出面板，也可通过原有按钮展开。双击分隔条切换展开状态。
- 键盘方向键调整宽度，Home 收起、End 展到可用最大宽度；拖动中按 Escape 或窗口失焦会取消本次调整。

## 实现

`SplitHandle` 在面板隐藏时保持挂载，并保留 Pointer Capture（指针捕获），因此同一次按住操作可以跨越收起状态。拖动使用初始位置计算绝对位移，避免收起后尺寸归零造成反向拖动跳变。每帧更新 CSS 宽度与透明度，只有跨越阈值及松手时更新面板状态。减少动画模式关闭展开补间，直接拖动仍跟随指针。原生网页预览在调整尺寸期间沿用已有临时隐藏机制。

这是桌面布局功能，手机界面继续使用原来的会话列表与单面板导航。设置页面保留独立导航布局。

## 局部验证

已检查左右栏不松手收起/恢复、渐隐、最小宽度吸附、Escape 取消、亮暗模式；构建和阈值边界单元检查通过。没有发送 Agent 消息，也没有运行全量桌面或手机回归。
