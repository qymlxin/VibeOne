# VibeOne 交互设计原型

这是可丢弃的 UI 原型，用于比较桌面工作台和手机审批的结构，不连接 Agent，不执行命令，也不保存业务数据。刷新重置模拟状态。

仓库根运行 `npm install`，然后 `npm run prototype`，访问 http://127.0.0.1:4173 。

三种结构通过 URL 或底部原型工具条切换：

- `?variant=focus`：聚焦会话，右侧变更按需展开。
- `?variant=workbench`：并列工作台，会话与文件上下文同时可见。
- `?variant=overview`：任务总览，先筛选和查看任务，再进入执行详情。

追加 `&device=mobile` 可以在桌面查看手机宽度；真实窄屏自动切换单列。工具条另有断线、其他设备处理与重置模拟。

右上角“外观主题”提供亮色、暗色和跟随系统。默认跟随系统，选择保存到本机 `localStorage` 的 `vibeone-theme`，刷新后保留；业务模拟数据仍在刷新时重置。跟随系统时实时响应操作系统外观变化。浏览器无法访问本地存储时，主题仍可在当前页面切换。

界面采用中性表面与石墨色操作，状态色用于审批、运行、完成及代码差异。`src/theme.css` 集中维护亮暗语义色及视觉细节，`src/style.css` 保留布局与响应式规则。手机审批、离线提示、输入框、滚动条、焦点状态及图形 Logo 均随主题适配。

默认使用紧凑布局，间距由 `src/compact.css` 统一调整：缩小外围留白、导航宽度、会话行、标题区、消息分组与输入区间距，保留正文字号。聚焦布局的会话列表位于导航正常文档流中，可独立滚动；手机主要操作仍保留 44–48px 的点击范围。

可操作：切换会话、搜索、查看工具调用和 diff、审批/拒绝、取消、排队发送、创建空会话、手机导航与返回。所有命令和输出都是明确标记的演示数据。审批结果分为提交中、决定已发送、后续工具结果三个阶段。

该原型没有建立生产用组件、权限或后端实现，不能直接作为正式版本发布。

品牌统一由 `BrandLogo` 组件处理：桌面导航用矢量图形＋真实文字，桌面顶部用真实文字，手机顶部用纯图形。文字使用本机系统字体，字重 700、字距 -0.025em；只影响品牌位，不加载额外字体文件。`assets/brand/` 中另提供图形、文字、组合三份透明背景 SVG；图形为纯路径，文字使用系统字体 `text` 元素。
