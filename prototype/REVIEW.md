# 三栏工作台 · 设计评审稿

这是独立、可丢弃的交互稿，尚未获得布局实施批准，不替换正式桌面端。固定用户指定的三栏方向，以右侧面板状态展示功能差别，不另做相互冲突的布局方案。所有消息、文件、差异、运行记录与网页内容均为演示数据。

运行：在本分支工作目录执行 `npm run prototype -- --port 4175`，打开 `/review.html`。使用现有依赖即可，不连接 Host 或 Agent。

当前评审地址：<http://127.0.0.1:4175/review.html>

## 评审重点

- 左栏固定承载项目与会话；搜索只筛选演示会话，底部保留主机状态、设置与外观。
- 中栏始终是对话。用户消息靠右，说明、执行摘要与结果用段距和细线分组；底部输入独立固定，侧边短线用于跳转轮次。
- 右栏按需切换变更、文件、终端与浏览，关闭后对话扩展；拖动分隔线或聚焦后用左右键调整宽度，另有扩大入口。
- 变更采用统一差异视图，文件树在右边；文件页只读预览。点击聊天里的文件名直接打开文件页。
- 点击聊天里的网址打开侧边浏览示意页，地址输入仅改变演示状态，不访问站点。正式版需处理加载中、失败、站点拒绝内嵌与系统浏览器打开。
- 终端稿展示 Agent 的只读执行记录。可交互 Shell 是否需要单独授权与生命周期管理，在功能实现前另行确定。
- 外观含亮色、暗色与系统选项；本稿状态仅在内存保存。最低评审桌面宽度为 960px；手机布局本轮不重新设计。

## 操作与状态

右上工具按钮与右侧标签切换同一面板；文件树可选择文件与筛选。读取/命令摘要可展开；发送消息只追加演示消息，不实际调用模型。设置和新建入口仅反馈设计稿状态。当前不提供真实文件编辑、Git 操作或网页执行。

右侧先保留一个工作面板，切换不挤掉聊天。正式重构前待确认是否需要多页签、多终端、真正的内嵌 WebView，以及对话区最小宽度。

## 新 Logo 与外观（本轮更新）

Logo 取自用户提供的 HTML 图稿：四条逐级收窄的圆角横条，viewBox 为 100 × 100，宽度依次为 96/72/48/24，高度均为 14，圆角为 7；末条及 One 为紫色。图形实现为内联 SVG，并保留透明背景的亮暗独立 SVG；不引入压缩包中的运行时代码。品牌文字沿用本机系统字体，Vibe 字重 500、One 字重 700，不加载新字体。Logo 紫色固定于品牌，界面强调色单独可调。

默认亮色背景为 `#FFFFFF`、前景为 `#1A1C1F`；默认暗色背景为 `#181818`、前景为 `#FFFFFF`。侧栏、输入与设置表面使用中性层级。设置入口位于左下角，亦可直接打开 `/review.html?view=appearance`。

外观页支持亮色、暗色、跟随系统（实时响应系统变化），四个强调色预设及自定义强调色，背景和前景取色、对比度显示、当前模式恢复默认。自定义背景/前景会同步派生侧栏、输入框、分隔线与次级文字。亮暗自定义值分开保留于内存，强调色共用，刷新重置。返回工作台即可查看整体效果，不改变正式应用设置。
